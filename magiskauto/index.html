MagiskAuto

Root your Google Pixel 6a or Samsung Galaxy Note 10 with Magisk. It shows you where to download your phone's exact firmware, then extracts and patches it for you.

Download MagiskAuto.exe for Windows

Version 1.3.1 · 8.5 MB · Windows 10/11 (64-bit) · All releases & release notes

⚠️ Before you start

  • Your phone's bootloader must be unlocked first, and unlocking erases everything on the phone. Back up first.
  • US and Canada Note 10 models (SM-N970U / U1 / W) can't be unlocked, so they can't be rooted. The international Exynos SM-N970F works.
  • Rooting can void your warranty and stop some apps (such as banking apps) from working. You use this at your own risk.

How to use it

  1. Download MagiskAuto.exe above.
  2. On the phone, turn on USB debugging: Settings → About phone, tap Build number 7 times, then Developer options → USB debugging. Plug the phone into the PC and allow the connection.
  3. Double-click MagiskAuto.exe and choose your phone. The first time, it offers to set up adb and fastboot for you, from Google's official platform-tools. Then it shows the link to the right firmware for your phone.
  4. When the firmware has downloaded, drag the file into the MagiskAuto window and press Enter. It does the rest.

If Windows doesn't see the phone, install the Google USB Driver (Pixel) or the Samsung USB Driver (Note 10).

Windows may show a "Windows protected your PC" warning because the app isn't code-signed. Click More info → Run anyway.

Google Pixel 6a

  • Firmware: Google factory images (the factory image for your build, not the OTA)
  • Patches boot.img
  • Can flash it for you automatically
  • Keeps a copy of the stock image so you can undo it

Samsung Galaxy Note 10

  • Firmware: SamFw, SamMobile or Bifrost
  • Patches the AP file for Odin
  • Puts the BL, CP and CSC files next to it, ready for Odin
  • Afterwards, start the phone with Vol Up + Power (let go at the warning) to boot with root

Already have Magisk?

  • To update Magisk itself, you don't need this program: open the Magisk app → Install → Direct Install.
  • Lost root after a system update? Run MagiskAuto again with the firmware for the new build. It detects your Magisk and asks before re-patching.
  • Note 10: when re-patching, use HOME_CSC in Odin to keep your data. MagiskAuto puts it in the output folder.
