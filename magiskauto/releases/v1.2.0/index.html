MagiskAuto v1.2.0

Newer version available: v1.4.1

Released November 10, 2026

Download MagiskAuto.exe

8.5 MB · Windows 10/11 (64-bit)

What's new

  • Windows .exe. Double-click it and pick your phone. You don't need Python or any scripts.
  • Download links instead of downloads. It reads your phone's exact build and shows you where to download the matching firmware: Google factory images for the Pixel 6a, and SamFw, SamMobile or Bifrost for the Note 10.
  • Drag and drop. When the firmware has downloaded, drag the file into the window.
  • Note 10: the BL, CP and CSC files are now saved next to the patched AP, so everything Odin needs is in one folder.
  • Use MagiskAuto.exe --links to only show the download links.

You'll also need

  • Android platform-tools. Unzip it next to MagiskAuto.exe.
  • A phone with an unlocked bootloader and USB debugging turned on.

Full instructions →

Known issues

  • Windows SmartScreen warns that the app isn't signed. Click More info → Run anyway.
  • The phone has to be plugged in when MagiskAuto starts, even before you choose the firmware file.
