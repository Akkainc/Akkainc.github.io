MagiskAuto v1.3.1

Newer version available: v1.7.3

Released November 10, 2026

Download MagiskAuto.exe

8.5 MB · Windows 10/11 (64-bit)

What's new

  • Knows when Magisk is already installed. It tells you, and asks before re-patching. This works even if the Magisk app is hidden.
  • Points to the quicker way to update Magisk. To update Magisk itself, use Magisk app → Install → Direct Install. You don't need a PC.
  • Note 10: keeps your data when re-patching. HOME_CSC is now extracted too, and is recommended when the phone is already rooted. The first time still uses CSC, which wipes the phone.
  • Hidden Magisk app: in app mode it no longer installs a second Magisk app. It asks you to open your hidden one.

You'll also need

  • A phone with an unlocked bootloader and USB debugging turned on.
  • An internet connection the first time, to fetch platform-tools and the Magisk app.
  • If Windows doesn't see the phone: the Google USB Driver (Pixel) or the Samsung USB Driver (Note 10).

Known issues

  • Windows SmartScreen warns that the app isn't signed. Click More info → Run anyway.
  • The phone has to be plugged in when MagiskAuto starts, even before you choose the firmware file.
