MagiskAuto v1.4.0

Newer version available: v1.7.6

Released November 10, 2026

Download MagiskAuto.exe

8.5 MB · Windows 10/11 (64-bit)

What's new

  • Finds Magisk on its own, including on your phone. You don't need to give a path. MagiskAuto uses the first one it finds:
    1. a Magisk*.apk next to MagiskAuto.exe
    2. the Magisk app installed on the phone, so the patch matches your Magisk version
    3. a Magisk*.apk in the phone's Download folder
    4. the latest Magisk from GitHub
  • Use a file on the phone yourself: MagiskAuto.exe -m phone:/sdcard/Download/Magisk-v28.1.apk
  • Every Magisk file is checked before it's used. Hidden-app stubs and wrong files are skipped, with a clear message.

You'll also need

  • A phone with an unlocked bootloader and USB debugging turned on.
  • An internet connection the first time, to fetch platform-tools and the Magisk app.
  • If Windows doesn't see the phone: the Google USB Driver (Pixel) or the Samsung USB Driver (Note 10).

Known issues

  • Windows SmartScreen warns that the app isn't signed. Click More info → Run anyway.
  • The phone has to be plugged in when MagiskAuto starts, even before you choose the firmware file.
