MagiskAuto v1.5.0

Newer version available: v1.7.6

Released November 10, 2026

Download the package (.zip)

18 MB · MagiskAuto.exe + Magisk app + guide · just the .exe (8.6 MB)

What's new

  • Everything in one package. One zip with MagiskAuto.exe, the official Magisk app and a quick-start guide (README.txt) for both phones.
  • One setup step. On first run, MagiskAuto gets your PC ready:
    • adb and fastboot (press Enter)
    • Pixel 6a: installs the Google USB Driver (Windows asks for permission)
    • Note 10: checks for the Samsung USB Driver and opens Samsung's download page if it's missing
    Run MagiskAuto.exe --setup to only prepare the PC.
  • Includes everything from v1.4.1: no more hanging at "Waiting for fastboot".

Not included

  • Odin (Note 10 only). Samsung doesn't allow it to be shared. Get it before you flash the Note 10.
  • The Samsung USB Driver, which comes only from Samsung's site. MagiskAuto opens that page for you.
  • Firmware, which is too large to include and differs for each phone. MagiskAuto shows you the right download link.

Known issues

  • Windows SmartScreen warns that the app isn't signed. Click More info → Run anyway.
  • The phone has to be plugged in when MagiskAuto starts, even before you choose the firmware file.
